# Global Infrastructure

![CPP](https://img.shields.io/badge/CPP-Cloud%20Practitioner-2EA44F?style=for-the-badge&logo=amazonaws&logoColor=white) ![SAA](https://img.shields.io/badge/SAA-Solutions%20Architect-0969DA?style=for-the-badge&logo=amazonaws&logoColor=white)

Learn how AWS organizes infrastructure geographically and how location choices affect availability, latency, compliance, and disaster recovery.

## What You Will Learn

- Differentiate Regions, Availability Zones, edge locations, Local Zones, and Wavelength Zones.
- Choose a deployment location from latency, resilience, and regulatory requirements.
- Explain why multi-AZ and multi-Region designs solve different problems.

## Recommended Study Order

| Order | Topic | What it covers |
|---:|---|---|
| 1 | [Aws Local Zones](aws-local-zones/) | Study notes and decision points for Aws Local Zones. |

## Certification Focus

- **CPP:** Recognize infrastructure components and their basic purpose.
- **SAA:** Use location and failure-domain choices in resilient architectures.

## How to Study This Section

1. Read the topics in the suggested order.
2. Write down the problem each service or concept solves.
3. Compare similar options using the decision guides.
4. Revisit the official AWS documentation for volatile features, pricing, quotas, or availability.
