# AWS Global Accelerator

## Overview

Study global anycast entry points and traffic routing over the AWS global network.

## Learning Objectives

- Explain how static anycast IP addresses provide stable global entry points.
- Distinguish Global Accelerator from DNS routing and content caching.
- Identify latency, availability, and failover use cases.

## Certification Focus

- **CPP:** Service recognition and global-network awareness.
- **SAA:** Global application entry points, endpoint health, failover, and performance decisions.

## Study Tips

- Focus on the service purpose before memorizing features.
- Note the requirements that make this service a better or worse choice than alternatives.
- Review security, availability, operations, and cost together.
