## Overview

Study the network boundary for AWS workloads, including subnets, routes, security controls, and connectivity.

## Learning Objectives

- Explain CIDR ranges, subnets, route tables, and internet connectivity.
- Distinguish security groups, flow logs, endpoints, peering, and NAT.
- Choose VPN gateway components and private connectivity patterns.

## Certification Focus

- **CPP:** VPC purpose and recognition of core networking components.
- **SAA:** Subnet design, routing, connectivity, security, and highly available network architecture.

## Study Tips

- Focus on the service purpose before memorizing features.
- Note the requirements that make this service a better or worse choice than alternatives.
- Review security, availability, operations, and cost together.
