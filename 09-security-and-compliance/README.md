# Security and Compliance

![CPP](https://img.shields.io/badge/CPP-Cloud%20Practitioner-2EA44F?style=for-the-badge&logo=amazonaws&logoColor=white) ![SAA](https://img.shields.io/badge/SAA-Solutions%20Architect-0969DA?style=for-the-badge&logo=amazonaws&logoColor=white)

Map security requirements to identity, encryption, detection, network protection, data protection, and compliance services.

## What You Will Learn

- Distinguish preventive, detective, responsive, and compliance controls.
- Choose encryption, secrets, threat-detection, vulnerability, data-discovery, and web-protection services.
- Apply defense in depth and shared responsibility to architecture scenarios.

## Certification Focus

- **CPP:** Security responsibilities, service recognition, and compliance resources.
- **SAA:** Layered controls, least privilege, encryption, network filtering, and detection architecture.

## How to Study This Section

1. Read the topics in the suggested order.
2. Write down the problem each service or concept solves.
3. Compare similar options using the decision guides.
4. Revisit the official AWS documentation for volatile features, pricing, quotas, or availability.
