# Archive

The archive preserves traceability; it is not a trash folder. Files enter it only after review and an approved migration decision. Archived material remains available to explain provenance, consolidation, or historical terminology.

> [!IMPORTANT]
> No existing file is moved into the archive during Phase 2.

| Area | Purpose | Status |
|---|---|---|
| [Duplicate versions](duplicate-versions/README.md) | Retained sources after useful content is merged | Empty foundation |
| [Obsolete notes](obsolete-notes/README.md) | Historical terminology or retired services | Empty foundation |
| [Uncategorized](uncategorized/README.md) | Material awaiting classification | Empty foundation |
| [Original prompts](original-prompts/README.md) | Authoring provenance retained after review | Empty foundation |
