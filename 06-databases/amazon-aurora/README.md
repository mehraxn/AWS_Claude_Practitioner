# Amazon Aurora

![CPP](https://img.shields.io/badge/CPP-Cloud%20Practitioner-2EA44F?style=for-the-badge&logo=amazonaws&logoColor=white) ![SAA](https://img.shields.io/badge/SAA-Solutions%20Architect-0969DA?style=for-the-badge&logo=amazonaws&logoColor=white)

## Overview

Study the AWS-designed relational database in the Amazon RDS family.

## Learning Objectives

- Explain Aurora cluster storage, writers, readers, endpoints, and failover.
- Compare provisioned Aurora and Aurora Serverless.
- Evaluate availability, scaling, recovery, and cost.

## Certification Focus

- **CPP:** Managed relational database recognition and availability.
- **SAA:** Cluster endpoints, replicas, failover, serverless capacity, and architecture decisions.

## Study Tips

- Focus on the service purpose before memorizing features.
- Note the requirements that make this service a better or worse choice than alternatives.
- Review security, availability, operations, and cost together.
