# Databases

![CPP](https://img.shields.io/badge/CPP-Cloud%20Practitioner-2EA44F?style=for-the-badge&logo=amazonaws&logoColor=white) ![SAA](https://img.shields.io/badge/SAA-Solutions%20Architect-0969DA?style=for-the-badge&logo=amazonaws&logoColor=white)

Compare managed relational, NoSQL, and in-memory database services.

## What You Will Learn

- Choose a database from the data model and access pattern.
- Explain Multi-AZ, read replicas, backups, failover, and scaling.
- Distinguish RDS, Aurora, DynamoDB, and ElastiCache.

## Recommended Study Order

| Order | Topic | What it covers |
|---:|---|---|
| 1 | [Amazon Aurora](amazon-aurora/) | AWS-designed MySQL- and PostgreSQL-compatible relational database clusters. |
| 2 | [Amazon DynamoDB](amazon-dynamodb/) | Serverless key-value and document database for predictable low-latency access. |
| 3 | [Amazon ElastiCache](amazon-elasticache/) | Managed in-memory caching for application performance. |
| 4 | [Amazon RDS](amazon-rds/) | Managed relational databases with backups, patching, Multi-AZ, and read replicas. |

## Certification Focus

- **CPP:** Recognize managed database categories and operational benefits.
- **SAA:** Make data-model, consistency, availability, scaling, recovery, and cost decisions.

## How to Study This Section

1. Read the topics in the suggested order.
2. Write down the problem each service or concept solves.
3. Compare similar options using the decision guides.
4. Revisit the official AWS documentation for volatile features, pricing, quotas, or availability.
