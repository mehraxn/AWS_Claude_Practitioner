# AWS Prescriptive Guidance

## Simple definition

AWS Prescriptive Guidance is a collection of AWS expert recommendations, best practices, strategies, and step-by-step patterns that help organizations design, migrate, modernize, secure, and optimize workloads on AWS.

It is not a core infrastructure service like Amazon EC2 or Amazon S3. It is more like an AWS knowledge and guidance resource.

---

## Core idea in plain English

Think of AWS Prescriptive Guidance as AWS telling you the best way to do something.

Instead of only giving service documentation, AWS also gives practical guidance such as

 what approach to choose
 what best practices to follow
 what architecture pattern to use
 what migration strategy makes sense
 what common mistakes to avoid

So the main idea is

AWS Prescriptive Guidance helps you make better decisions and follow proven methods when using AWS.

---

## Main use cases

### 1. Cloud migration planning

A company moving from on-premises to AWS can use Prescriptive Guidance to understand migration strategies, phases, and best practices.

### 2. Modernization projects

Teams can learn recommended approaches for modernizing applications, operations, and architectures.

### 3. Security and governance design

Organizations can use AWS guidance to build secure and well-governed AWS environments.

### 4. Architecture patterns

Builders can use step-by-step patterns for real technical scenarios, such as migration paths, integrations, and design decisions.

### 5. Operational best practices

Teams can learn proven ways to improve reliability, automation, and cloud operations.

## How it works

AWS publishes Prescriptive Guidance as online content, guides, frameworks, and patterns.

You read the guidance when you are trying to solve a cloud problem or plan an AWS project.

For example, AWS might provide

 a migration strategy guide
 a security reference architecture
 a pattern for moving a workload to AWS
 a set of best practices for governance or operations

These resources usually explain

 the problem
 the recommended solution
 the architecture idea
 the steps to follow
 the tools or AWS services involved

So it works as a trusted AWS reference for how to do things correctly.

## Related AWS services and differences

### AWS Prescriptive Guidance vs AWS Documentation

 AWS Documentation explains how a service works
 AWS Prescriptive Guidance explains recommended ways to solve real problems using AWS

Documentation is broader and service-focused.
Prescriptive Guidance is more solution-focused and best-practice-focused.

### AWS Prescriptive Guidance vs AWS Well-Architected Framework

 AWS Well-Architected Framework gives principles for building high-quality cloud workloads
 AWS Prescriptive Guidance gives more practical guidance, strategies, patterns, and implementation recommendations

Well-Architected asks, “Is this workload designed well”
Prescriptive Guidance helps answer, “What is the recommended way to do this”

### AWS Prescriptive Guidance vs AWS Cloud Adoption Framework (AWS CAF)

 AWS CAF helps organizations plan cloud transformation across business and technical areas
 AWS Prescriptive Guidance often expands on these ideas with more specific guidance and examples

CAF is a transformation framework.
Prescriptive Guidance is the detailed recommendation layer.

### AWS Prescriptive Guidance vs AWS Trusted Advisor

 Trusted Advisor checks your AWS environment and gives recommendations
 AWS Prescriptive Guidance provides published best-practice content and patterns

Trusted Advisor analyzes your environment.
Prescriptive Guidance teaches you recommended approaches.

### AWS Prescriptive Guidance vs AWS Professional Services

 AWS Professional Services are AWS experts who can help directly with projects
 AWS Prescriptive Guidance is published guidance you can read and apply yourself

One is human consulting support.
The other is a knowledge resource.

## Common exam traps

### Trap 1 Thinking it is a compute or management service

AWS Prescriptive Guidance does not run applications, store files, or monitor systems.
It gives guidance and patterns.

### Trap 2 Confusing it with AWS documentation

Documentation tells you how services work.
Prescriptive Guidance tells you recommended approaches and best practices.

### Trap 3 Confusing it with AWS Well-Architected Tool

The Well-Architected Tool helps review workloads.
Prescriptive Guidance provides reference material, patterns, and strategies.

### Trap 4 Assuming it is only for developers

It is useful for architects, managers, technical leads, migration teams, and decision-makers too.

### Trap 5 Overthinking the exam

If a question asks for best practices, recommended migration patterns, or expert guidance for cloud adoption, AWS Prescriptive Guidance is a strong clue.
