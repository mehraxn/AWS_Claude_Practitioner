# Known Limitations

## Coverage

- Phase 6 completed all 54 authorized backlog items, not every official exam-guide task. The CPP dashboard retains 51 and the SAA dashboard 58 rows with less than complete evidence.
- Badges indicate supported relevance and depth; they do not certify complete coverage.
- The notes do not guarantee exam success and are not a replacement for current official exam guides.

## Learning experience

- Twenty-eight existing files contain knowledge-check questions without a nearby answer section or explanation. The Phase 7 exam-scenario guides do include explained reasoning.
- Hands-on labs, live AWS-console exercises, and a complete mock-exam system are outside this release.

## References and freshness

- Thirteen reference-QA rows lack a dedicated `## References` heading. Twelve are service lessons that still contain official inline links; the remaining row is the navigation-only repository README.
- Free Tier offers, Support details, prices, quotas, certification scope, product names, and Regional availability can change after the recorded checked dates.
- Wavelength, Snow Family, migration source/target support, and hardware or ordering options require live verification before operational use.
- Five Mermaid-bearing files were manually inspected, but automated rendering was unavailable because the Mermaid CLI is not installed.

## Local hygiene

An ignored local `scripts/__pycache__/` directory exists. It is not tracked or included in the release diff.

## Exam integrity

Practice material is original study content. The repository intentionally excludes exam dumps and recalled live-exam questions.
