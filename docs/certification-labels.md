# Certification Labels

## CPP

![CPP](https://img.shields.io/badge/CPP-Cloud%20Practitioner-2EA44F?style=for-the-badge&logo=amazonaws&logoColor=white)

Use for topics supported by the current Cloud Practitioner scope. Awareness-level means learners should recognize the service, purpose, benefits, common use cases, and basic cost or responsibility concepts without implementation depth. A core CPP topic deserves fuller foundational treatment.

## SAA

![SAA](https://img.shields.io/badge/SAA-Solutions%20Architect-0969DA?style=for-the-badge&logo=amazonaws&logoColor=white)

Use for topics supported by the current Solutions Architect – Associate scope. Core SAA topics require architecture decisions, integrations, resilience, security, performance, cost, and trade-offs.

## Both and Uncertain Classifications

Display both badges when official scope evidence supports both: for example, Amazon EC2 can introduce compute and pricing for CPP while adding placement, resilience, scaling, and storage decisions for SAA. An awareness-only service should not be expanded merely because it has a badge. If mapping evidence is incomplete or conflicting, write `Classification: review required` instead of guessing.

Examples: an Amazon S3 lesson may use both badges; a general cloud-benefits lesson may be CPP core and SAA foundation; a niche service absent from reviewed exam guides remains uncertain until verified.
