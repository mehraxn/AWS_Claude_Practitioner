# Migration and Hybrid Cloud

![CPP](https://img.shields.io/badge/CPP-Cloud%20Practitioner-2EA44F?style=for-the-badge&logo=amazonaws&logoColor=white) ![SAA](https://img.shields.io/badge/SAA-Solutions%20Architect-0969DA?style=for-the-badge&logo=amazonaws&logoColor=white)

Plan workload and data movement between on-premises environments and AWS.

## What You Will Learn

- Distinguish discovery, database migration, file transfer, offline transfer, and hybrid services.
- Choose migration tools from data type, downtime, bandwidth, scale, and target architecture.
- Explain the roles of Outposts, Storage Gateway, Snowball Edge, DataSync, DMS, and Migration Hub.

## Recommended Study Order

| Order | Topic | What it covers |
|---:|---|---|
| 1 | [AWS Application Discovery Service](aws-application-discovery-service/) | Discovery of on-premises servers and dependencies for migration planning. |
| 2 | [AWS Database Migration Service (DMS)](aws-database-migration-service/) | Migration and replication of databases with reduced downtime. |
| 3 | [AWS DataSync](aws-datasync/) | Online transfer of files and object data to and from AWS storage. |
| 4 | [AWS Migration Hub](aws-migration-hub/) | Central tracking and coordination of migration progress. |
| 5 | [AWS Outposts](aws-outposts/) | AWS infrastructure and services delivered to on-premises locations. |
| 6 | [AWS Schema Conversion Tool (SCT)](aws-schema-conversion-tool/) | Conversion of database schemas between different engines. |
| 7 | [AWS Snowball Edge](aws-snowball-edge/) | Offline data transfer and edge computing appliances. |

## Certification Focus

- **CPP:** Recognize migration and hybrid-cloud services.
- **SAA:** Select migration paths and hybrid designs that meet technical constraints.

## How to Study This Section

1. Read the topics in the suggested order.
2. Write down the problem each service or concept solves.
3. Compare similar options using the decision guides.
4. Revisit the official AWS documentation for volatile features, pricing, quotas, or availability.
