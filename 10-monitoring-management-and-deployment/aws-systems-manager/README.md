# AWS Systems Manager

![CPP](https://img.shields.io/badge/CPP-Cloud%20Practitioner-2EA44F?style=for-the-badge&logo=amazonaws&logoColor=white) ![SAA](https://img.shields.io/badge/SAA-Solutions%20Architect-0969DA?style=for-the-badge&logo=amazonaws&logoColor=white)

## Overview

Study secure fleet operations and automation for AWS and hybrid resources.

## Learning Objectives

- Explain Systems Manager as a collection of operational capabilities.
- Use Session Manager as an alternative to direct administrative access.
- Recognize automation, patching, inventory, and parameter-management use cases.

## Lesson Order

## Certification Focus

- **CPP:** Operational-management service recognition.
- **SAA:** Secure access, fleet operations, automation, and reduced bastion-host dependence.

## Study Tips

- Focus on the service purpose before memorizing features.
- Note the requirements that make this service a better or worse choice than alternatives.
- Review security, availability, operations, and cost together.
