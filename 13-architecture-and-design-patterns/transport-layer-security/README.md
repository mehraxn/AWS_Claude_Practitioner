# Transport Layer Security

## Overview

Understand where TLS can terminate and how certificates are used across application paths.

## Learning Objectives

- Explain TLS termination at load balancers and application endpoints.
- Relate certificate management to Elastic Load Balancing and databases.
- Choose an encryption path from end-to-end security requirements.

## Lesson Order

| Order | Topic | What it covers |
|---:|---|---|
| 1 | [SSL Termination — Complete](01-ssl-termination.md) | Where TLS is terminated and which component manages certificates. |
| 2 | [SSLTLS with Load Balancer and RDS](02-tls-with-load-balancers-and-rds.md) | TLS paths involving load balancers, applications, RDS, and Aurora. |

## Certification Focus

- **CPP:** Encryption-in-transit awareness.
- **SAA:** Certificate placement, TLS termination, and secure application architecture.

## Study Tips

- Focus on the service purpose before memorizing features.
- Note the requirements that make this service a better or worse choice than alternatives.
- Review security, availability, operations, and cost together.
