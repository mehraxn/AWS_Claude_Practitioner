# Security Architecture Patterns

![CPP](https://img.shields.io/badge/CPP-Cloud%20Practitioner-2EA44F?style=for-the-badge&logo=amazonaws&logoColor=white) ![SAA](https://img.shields.io/badge/SAA-Solutions%20Architect-0969DA?style=for-the-badge&logo=amazonaws&logoColor=white)

## Overview

Apply AWS services in layered security and governance designs.

## Learning Objectives

- Protect data at rest and in transit.
- Use account boundaries and centralized governance.
- Connect identity, encryption, logging, detection, and network controls.

## Lesson Order

| Order | Topic | What it covers |
|---:|---|---|
| 1 | [Data Protection Patterns on AWS](01-data-protection-patterns.md) | Encryption, key management, secrets, backups, and protected data flows. |
| 2 | [Multi-Account Governance on AWS](02-multi-account-governance.md) | Account boundaries, organizations, guardrails, and centralized controls. |

## Certification Focus

- **CPP:** Security best-practice awareness.
- **SAA:** Defense in depth, data protection, and multi-account governance.

## Study Tips

- Focus on the service purpose before memorizing features.
- Note the requirements that make this service a better or worse choice than alternatives.
- Review security, availability, operations, and cost together.
