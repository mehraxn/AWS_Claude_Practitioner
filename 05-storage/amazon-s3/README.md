# Amazon S3

![CPP](https://img.shields.io/badge/CPP-Cloud%20Practitioner-2EA44F?style=for-the-badge&logo=amazonaws&logoColor=white) ![SAA](https://img.shields.io/badge/SAA-Solutions%20Architect-0969DA?style=for-the-badge&logo=amazonaws&logoColor=white)

## Overview

Study object storage, storage classes, and lifecycle-based cost management.

## Learning Objectives

- Explain buckets, objects, durability, access, and common use cases.
- Select an S3 storage class from access frequency and retrieval needs.
- Use lifecycle rules to transition or expire objects.

## Certification Focus

- **CPP:** Object storage recognition, durability, classes, and lifecycle basics.
- **SAA:** Storage-class selection, cost, access patterns, protection, and data management.

## Study Tips

- Focus on the service purpose before memorizing features.
- Note the requirements that make this service a better or worse choice than alternatives.
- Review security, availability, operations, and cost together.
