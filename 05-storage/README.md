# Storage

![CPP](https://img.shields.io/badge/CPP-Cloud%20Practitioner-2EA44F?style=for-the-badge&logo=amazonaws&logoColor=white) ![SAA](https://img.shields.io/badge/SAA-Solutions%20Architect-0969DA?style=for-the-badge&logo=amazonaws&logoColor=white)

Learn when to use object, block, file, temporary, backup, and hybrid storage.

## What You Will Learn

- Distinguish S3, EBS, EFS, FSx, instance store, and Storage Gateway.
- Select storage from access pattern, durability, performance, sharing, and cost.
- Use lifecycle, backup, and hybrid storage concepts in architecture scenarios.

## Recommended Study Order

| Order | Topic | What it covers |
|---:|---|---|
| 1 | [Amazon EBS](amazon-ebs/) | Persistent block storage for EC2 instances. |
| 2 | [Amazon EFS](amazon-efs/) | Elastic shared file storage for Linux workloads. |
| 3 | [Amazon FSx](amazon-fsx/) | Managed file-system choices for Windows, Lustre, OpenZFS, and NetApp ONTAP workloads. |
| 4 | [Amazon FSx for Lustre](amazon-fsx-for-lustre/) | High-performance parallel file storage for compute-intensive workloads. |
| 5 | [Amazon FSx for Windows File Server](amazon-fsx-for-windows-file-server/) | Managed Windows file shares using SMB. |
| 6 | [Amazon S3](amazon-s3/) | Durable object storage, storage classes, and lifecycle management. |
| 7 | [AWS Backup](aws-backup/) | Centralized policy-based backup across supported AWS services. |
| 8 | [AWS Storage Gateway](aws-storage-gateway/) | Hybrid storage interfaces that connect on-premises environments to AWS storage. |
| 9 | [Amazon EC2 Instance Store](ec2-instance-store/) | Temporary block storage physically attached to the host computer. |

## Certification Focus

- **CPP:** Recognize storage categories and common use cases.
- **SAA:** Choose storage based on performance, availability, durability, and access requirements.

## How to Study This Section

1. Read the topics in the suggested order.
2. Write down the problem each service or concept solves.
3. Compare similar options using the decision guides.
4. Revisit the official AWS documentation for volatile features, pricing, quotas, or availability.
