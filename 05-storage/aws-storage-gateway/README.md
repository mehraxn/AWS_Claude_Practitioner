# AWS Storage Gateway

![CPP](https://img.shields.io/badge/CPP-Cloud%20Practitioner-2EA44F?style=for-the-badge&logo=amazonaws&logoColor=white) ![SAA](https://img.shields.io/badge/SAA-Solutions%20Architect-0969DA?style=for-the-badge&logo=amazonaws&logoColor=white)

## Overview

Compare hybrid file, volume, and tape gateway modes.

## Learning Objectives

- Explain how Storage Gateway connects on-premises applications to AWS storage.
- Distinguish File Gateway, cached volumes, stored volumes, and Tape Gateway.
- Choose a mode from protocol, local-latency, backup, and capacity requirements.

## Certification Focus

- **CPP:** Recognize Storage Gateway as a hybrid-storage service.
- **SAA:** Select the correct gateway mode for hybrid architectures.

## Study Tips

- Focus on the service purpose before memorizing features.
- Note the requirements that make this service a better or worse choice than alternatives.
- Review security, availability, operations, and cost together.
